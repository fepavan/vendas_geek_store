# 🎮 Geek Store Sales Analysis

Este projeto foi desenvolvido para analisar o desempenho de vendas de uma loja de produtos geeks, permitindo o acompanhamento de métricas essenciais de negócio como receita, custos e lucros para otimizar a tomada de decisões.

---

## 🚀 Objetivos do Projeto

*   **Análise de Desempenho:** Calcular e avaliar o volume de vendas e faturamento de consoles, jogos e colecionáveis.
*   **Cálculo de Margens:** Identificar a lucratividade real de cada produto após subtrair os custos de fabricação.
*   **Exportação de Dados:** Estruturar e preparar uma base consolidada para alimentar painéis de visualização (BI).

---

## 📊 Métricas Calculadas

No decorrer do projeto, calculamos as seguintes colunas essenciais:

1.  **Receita:** `Preço de Venda * Quantidade Vendida`
2.  **Lucro Unidade:** `Preço de Venda - Custo Fabricante` (Ajustado no código para refletir o ganho por unidade)
3.  **Lucro Final:** `Lucro Unitário * Quantidade Vendida`
